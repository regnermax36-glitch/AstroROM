## 🛠 Installation Instructions

### Prerequisites
- **TWRP Recovery** installed on your device
- **One UI 8.0** (Android 14) based firmware
- **Unlocked bootloader**
- **At least 2GB free space** in system partition

### Installation Steps

1. **Backup Your System**
   ```
   - Boot into TWRP
   - Create a NANDroid backup
   - Backup EFS partition (recommended)
   ```

2. **Flash the Package**
   ```
   - Copy maxregnerOS_transformation.zip to your device
   - Boot into TWRP recovery
   - Select "Install" and choose the zip file
   - Swipe to confirm flash
   - Wait for installation to complete
   ```

3. **Post-Installation**
   ```
   - Wipe Dalvik/ART Cache
   - Wipe Cache partition
   - Reboot system
   - First boot may take 5-10 minutes
   ```

## 🆘 Troubleshooting

### Common Issues

**Boot Loop**
- Flash stock firmware via Odin
- Restore TWRP backup
- Check device compatibility

**Performance Issues**
- Clear Dalvik/ART cache
- Run maxregner-performance tool
- Check thermal throttling

**Audio Problems**
- Verify media file permissions
- Restart audio service
- Check audio policy configuration

**UI Glitches**
- Clear system UI cache
- Restart SystemUI service
- Check overlay permissions

### Recovery Options
```bash
# Restore original files
cp /data/maxregner_backup/* /system/

# Reset to defaults
/system/bin/maxregner/reset_defaults.sh

# Emergency recovery
fastboot flash system system.img
```
