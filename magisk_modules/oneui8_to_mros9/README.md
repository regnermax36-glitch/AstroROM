## 📦 Installation

### Prerequisites
- Rooted Samsung device with Magisk installed
- One UI 8 (recommended) or compatible Samsung firmware
- At least 4GB RAM (6GB+ recommended for full AI features)

### Installation Steps

1. **Download** the latest MROS 9 transformation module
2. **Open** Magisk Manager
3. **Navigate** to Modules section
4. **Install** from storage and select the module ZIP
5. **Reboot** your device
6. **Enjoy** your new MROS 9 experience!

### First Boot
- First boot may take 2-3 minutes longer due to optimizations
- MROS 9 OOBE will guide you through feature setup
- AI features will begin learning your usage patterns

## 🔍 Troubleshooting

### Common Issues

**Module not working after installation**
- Ensure device is properly rooted with Magisk
- Check compatibility with your One UI version
- Verify sufficient storage space

**Performance issues**
- Try switching to Balanced performance profile
- Clear system cache in recovery mode
- Check thermal throttling in logs

**AI features not working**
- Ensure device has sufficient RAM (6GB+ recommended)
- Check if AI features are enabled in configuration
- Restart MROS 9 service: `setprop persist.vendor.mros.restart true`

**Boot animation not showing**
- Verify bootanimation.zip permissions
- Check if custom boot animation is enabled
- Some devices may require additional steps

### Logs and Debugging
- Main log: `/data/local/tmp/mros9_transform.log`
- Service log: `/data/local/tmp/mros9_service.log`
- Configuration: `/data/system/mros9/config/`
